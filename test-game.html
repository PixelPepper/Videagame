Features Checklist

  • ✅ Roguelike gameplay with rounds
  • ✅ Multiple monster types (5 varieties)
  • ✅ Drop system (health, mana, power-ups, gold)
  • ✅ Upgrade menu between rounds
  • ✅ Dynamic difficulty scaling
  • ✅ Touch controls (joystick + buttons)
  • ✅ Music system with 5 tracks
  • ✅ Particle effects
  • ✅ Mobile-optimized UI
  • ✅ Android packaging setup

Build Instructions

  1. Test in Browser: Open index.html or run: python3 -m http.server 8000
  2. Build Android APK: Run: ./build-android.sh
  3. Install on Device: Enable USB debugging and run: cordova run android
